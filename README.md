# OSS Blog - 开源个人博客系统二次开发

> 本项目是基于 Ghost 开源博客平台进行的二次开发实验，实现了相关文章推荐、导航增强等自定义功能。

## 项目简介

本项目是一个基于 [Ghost](https://github.com/TryGhost/Ghost) 开源博客平台构建的个人博客系统。在保持 Ghost 核心功能不变的前提下，通过主题二次开发，实现了：

- ✅ 文章详情页底部显示“同标签相关文章推荐”（使用 `{{#get}}` 助手）
- ✅ 导航栏增强（增加“归档”和“关于”入口）
- ✅ 支持会员注册、登录、评论
- ✅ 支持文章标签分类与搜索
- ✅ 响应式设计，桌面/移动端均可用

## 目标用户与问题场景

- **目标用户**：个人博主、技术写作者、内容创作者
- **问题场景**：
  - 需要快速搭建一个可写作、可评论、可搜索的个人博客
  - 希望通过标签关联内容，提升读者阅读深度
  - 希望在不修改核心代码的前提下，通过主题定制实现个性化功能

## 技术栈

| 组件 | 技术 | 版本 |
| :--- | :--- | :--- |
| 博客平台 | Ghost | 5.x (具体版本见 `runtime/package.json`) |
| 主题引擎 | Handlebars | Ghost 内置 |
| 数据库 | SQLite | Ghost 内置 |
| 开发语言 | Node.js | 22 LTS |
| 包管理 | npm | 随 Node.js 安装 |
| 版本控制 | Git | 2.40+ |
| 主题构建 | Rollup | 主题自带 |

## 环境要求

- **Node.js**：22 LTS（与 Ghost 兼容）
- **npm**：随 Node.js 安装
- **Git**：2.40+
- **操作系统**：Windows 11 / Linux / macOS（本项目在 Windows 11 下开发和测试）
